MeetingScribe 설치 방법
========================

1. MeetingScribe.app 을 옆의 "응용 프로그램" 폴더로 끌어다 놓습니다.

2. 처음 실행할 때는 그냥 더블클릭하면 열리지 않습니다.
   응용 프로그램 폴더에서 MeetingScribe 를 마우스 오른쪽 클릭 →
   "열기" 를 누르고, 다시 한 번 "열기" 를 누르세요.
   (한 번만 하면 됩니다. 이후에는 그냥 더블클릭으로 열립니다.)

   * 이 과정이 필요한 이유: Apple 개발자 서명이 없는 앱이라
     macOS 가 처음에 차단합니다. 자체 서명만 되어 있습니다.

3. 첫 녹음 때 권한 요청이 두 번 뜹니다. 모두 허용해 주세요.
   - 마이크
   - 시스템 오디오 녹음

4. 결과물은 다음 위치에 저장됩니다.
   서류(Documents) > MeetingScribe > (날짜-시각) 폴더


필요 조건
---------
- macOS 26 이상
- Claude Code CLI 설치 및 로그인 완료
  (터미널에서 claude 명령이 동작해야 합니다)


사용법
------
1. 앱을 엽니다.
2. "회의" 또는 "강의" 를 고릅니다.
3. [녹음 시작] 을 누릅니다.
4. 끝나면 [중지하고 문서 만들기] 를 누릅니다.
5. 전사와 문서 작성이 끝나면 [결과 열기] 로 확인합니다.

용어 정확도를 높이려면
----------------------
앱 안의 용어 사전에 자주 쓰는 전문용어를 추가하면 정확도가 크게 올라갑니다.
MeetingScribe.app 을 오른쪽 클릭 → "패키지 내용 보기" →
Contents/Resources/templates/terms.txt 를 편집하세요.
