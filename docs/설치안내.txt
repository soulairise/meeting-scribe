MeetingScribe 설치 방법
========================

1. MeetingScribe.app 을 옆의 "응용 프로그램" 폴더로 끌어다 놓습니다.

2. 응용 프로그램 폴더에서 MeetingScribe 를 더블클릭합니다.
   "Apple은 악성 코드가 없음을 확인할 수 없습니다" 라는 창이 뜹니다.
   [완료] 를 누릅니다.

3. 시스템 설정 > 개인정보 보호 및 보안 을 엽니다.
   아래로 스크롤하면 "'MeetingScribe'이(가) 차단되었습니다" 라는 줄이 있습니다.
   옆의 [그래도 열기] 를 누르고, 암호 또는 Touch ID 로 확인합니다.

4. 다시 확인 창이 뜨면 [열기] 를 누릅니다.
   여기까지가 최초 1회입니다. 이후에는 그냥 더블클릭으로 열립니다.

   * 왜 이런가: Apple 개발자 서명이 없는 앱이라 macOS 가 차단합니다.
     자체 서명만 되어 있습니다.
   * macOS 14 까지 쓰던 "오른쪽 클릭 → 열기" 방법은
     macOS 15 부터 더 이상 동작하지 않습니다.

   터미널이 익숙하다면 아래 한 줄로 대신할 수 있습니다.
     xattr -d com.apple.quarantine /Applications/MeetingScribe.app

5. 첫 녹음 때 권한 요청이 두 번 뜹니다. 모두 허용해 주세요.
   - 마이크
   - 시스템 오디오 녹음

6. 결과물은 다음 위치에 저장됩니다.
   서류(Documents) > MeetingScribe > (날짜-시각) 폴더


필요 조건
---------
- macOS 26 이상
- Claude Code CLI 설치 및 로그인 완료
  (터미널에서 claude 명령이 동작해야 합니다)


사용법
------
1. 앱을 엽니다.
2. "회의" 또는 "강의" 를 고릅니다.
3. [녹음 시작] 을 누릅니다.
4. 녹음 중에는 받아적는 내용이 3~4줄씩 화면에 흘러갑니다.
5. 끝나면 [중지하고 문서 만들기] 를 누릅니다.
6. 전사와 문서 작성이 끝나면 [결과 열기] 로 확인합니다.


용어 정확도를 높이려면
----------------------
앱 안의 용어 사전에 자주 쓰는 전문용어를 추가하면 정확도가 크게 올라갑니다.
MeetingScribe.app 을 오른쪽 클릭 → "패키지 내용 보기" →
Contents/Resources/templates/terms.txt 를 편집하세요.
